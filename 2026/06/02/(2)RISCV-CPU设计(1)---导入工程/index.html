二、单元 LEF：让工具认识单元的外形和引脚

2.1 单元 LEF 和工艺 TLEF 的分工

物理库文件 LEF 描述单元的尺寸、引脚位置和布线阻挡，以及工艺的金属层和基本布线规则，是布局布线的基础输入。阅读时可以先分成两部分：

  • 工艺 TLEF：定义标准单元摆放用的 SITE，以及 LAYER、固定 VIA 和 VIARULE GENERATE 等工艺信息。
  • 标准单元 LEF、SRAM LEF：描述具体单元的大小、引脚和障碍物，并引用工艺 TLEF 中定义的层、site 或过孔。

先看 AN2D0BWP40P140。阅读顺序是：MACRO 单元名 → SIZE 尺寸 → SITE 摆放格子 → PIN 引脚 → OBS 阻挡。

2.3 RECT 怎么读：两个对角点确定一个矩形

RECT 是 Rectangle 的缩写。在 LEF 中，RECT x1 y1 x2 y2 ; 用左下角和右上角两个点描述一个矩形区域。单元里的图形坐标以本地坐标系为基准。

例如 RECT 0.485 0.125 0.535 0.755 ;，宽度是 0.535 - 0.485 = 0.050 µm，高度是 0.755 - 0.125 = 0.630 µm。一个引脚下面可以有多个 RECT，这些矩形共同描述它可供连接的形状。

代码 阅读重点
SIZE 0.560 BY 0.900 ; 单元宽 0.560 µm、高 0.900 µm
SITE core ; 引用工艺 TLEF 中名为 core 的摆放格子
PIN Z、DIRECTION OUTPUT Z 是输出引脚；A1、A2 是输入引脚
PORT → LAYER M1 → RECT 描述引脚在 M1 上的几何形状
PIN VDD / VSS、USE POWER / GROUND 描述电源、地引脚及其用途
OBS → LAYER → RECT 描述相应层上需要避让的布线阻挡

2.4 示例二：AN2D2 的 M2 引脚和 VIA 引用

再看 AN2D2BWP40P140。它的尺寸是 0.700 × 0.900 µm；A1、A2 的端口图形写在 M2 上，并在 PORT 中引用了 VIA12_square 过孔模板。

讲解时可以重点对比两个单元的 SIZE、A1/A2 所在层，以及 VIA 的写法。过孔模板的具体定义在第三章继续看。

2.5 CO 层上的 OBS 表示什么

CO（Contact）是接触孔层，通常用于穿过绝缘层，将下方的有源区或多晶硅与第一层金属 M1 接通。LEF 中 CO 层的 OBS 表示该层需要避让的阻挡区域。

三、工艺 TLEF：从原代码理解摆放和布线规则

这一章从一份 6,326 行的 Technology LEF 中挑出 10 组代码。每组先看原文，再解释它在布局布线里管什么。行号用于对照原始 TLEF，不是本篇 Markdown 的行号。代码中的 # … 表示节选时省略的行。M1 的完整规则片段保留在文末附录中，方便与各小节对照。

TLEF 给后端工具提供放置和布线共用的工艺定义。 单元 LEF 描述具体单元的外形、引脚和障碍物，并引用 TLEF 中定义的 site、层或过孔。

3.1 文件头：坐标单位、制造网格和扩展规则

原文件第 42–75 行。

  • BUSBITCHARS "[]" 用来表示总线位，例如 A[2]。DIVIDERCHAR "/" 给出层次分隔符。
  • DATABASE MICRONS 2000 表示 1 µm = 2,000 DBU，所以 1 DBU = 0.5 nm。MANUFACTURINGGRID 0.005 给出 5 nm 的几何对齐网格，相当于 10 DBU。
  • USEMINSPACING OBS OFF 让工具按 OBS 的实际形状计算间距。宽障碍物可以触发宽线间距规则。
  • PROPERTYDEFINITIONS 声明扩展属性。后面的 PROPERTY LEF58_SPACING "..." 会把具体间距规则写在引号里。这里的 MAXVIASTACK 4 NOSINGLE RANGE M1 M6 表示在 M1 到 M6 的范围内，叠超过四级时，该堆叠中的过孔都必须是多切孔过孔。

3.2 SITE core：标准单元摆放格子

原文件第 77–81 行。

core 是核心区的摆放格子，宽 0.14 µm、高 0.90 µm。标准单元 LEF 里的 SITE core ; 引用这里的定义。前面示例中的 AN2D2BWP40P140 是 0.700 × 0.900 µm，刚好是 一行高、五个 site 宽。SYMMETRY Y 表示该 site 支持关于 Y 轴镜像。

3.3 四种非布线层：PO、CO、VTUL_N 和 OVERLAP

原文件第 107–127、1594–1596 行。

类型 怎么读
PO / MASTERSLICE 底层器件工艺相关的层，这里是多晶硅层的抽象。
CO / CUT 接触孔层。ENCLOSURE ABOVE 描述上方图形怎样盖住孔。
VTUL_N / IMPLANT 与器件阈值相关的注入层。用这一段代表文件里重复出现的 VT* 层。
OVERLAP / OVERLAP 可以配合宏单元的 OBS 描述实际摆放占用范围，例如直角多边形的宏占地。

这里可以接回标准单元 LEF 的 OBS → LAYER CO → RECT。单元 LEF 给出障碍图形的坐标，TLEF 定义 CO 这种层。

3.4 LAYER M1：走线方向、轨道和线宽

原文件第 171–178 行。END M1 在第 268 行。

  • DIRECTION VERTICAL 表示 M1 优先竖走。竖线沿 Y 方向延伸，相邻两条竖向轨道在 X 方向隔 0.14 µm。
  • OFFSET 0.07 0.000 给出 X、Y 方向的起始偏移。按这组参数生成的竖向轨道可以落在 x = 0.07、0.21、0.35… µm。
  • WIDTH 0.05 是默认线宽，MINWIDTH 和 MAXWIDTH 给出线宽范围。

录屏画两根竖线时，把 PITCH 标在两条中心线之间，把 WIDTH 标在单根线的两条边之间，把 SPACING 标在两根线相邻的边之间。

3.5 M1 几何规则：面积、短边、平行间距和线端间距

原文件第 180–182、191–198、210–212 行。

  • AREA 看金属面积。 一块宽 0.05 µm 的独立矩形，单看这条基础规则，长度至少是 0.0115 ÷ 0.05 = 0.23 µm。
  • MINENCLOSEDAREA 看封闭孔洞的面积。 一块金属如果围出一个空洞，这里规定孔洞面积至少是 0.2 µm²。
  • MINSTEP 看轮廓短边。 这里连续短于 0.05 µm 的边最多允许一条。
  • SPACINGTABLE 用来查平行线间距。 两根线分别宽 0.20 和 0.05 µm，平行重叠 0.50 µm。用较大的线宽选 WIDTH 0.180 行，用平行长度选 PARALLELRUNLENGTH 0.470 列，交叉位置就是最小边到边间距 0.100 µm。
  • ENDOFLINE 检查线头。 第一条规则针对端边短于 0.070 µm 的线头，检查范围内要求间距 0.060 µm。WITHIN 0.025 描述沿线头两侧扩展的检查范围。第二条增加了平行邻边条件。

3.6 LAYER VIA1 和 MINIMUMCUT：切孔分类和数量

原文件第 270–275、337 行是切孔层节选，第 224–229 行是 M1 上的切孔数量规则。

  • LAYER VIA1 定义 M1 和 M2 之间的切孔层。VSINGLECUT 是 0.05 × 0.05 µm 的方孔。VDOUBLECUT 是 0.05 × 0.13 µm 的一个长孔，规则按两个 cut 计。
  • 以第一条 MINIMUMCUT 为例，宽度超过 0.18 µm 的 M1 线或引脚向上接时，按切孔类别要求两个 VSINGLECUT，或一个 VDOUBLECUT。这里的 WITHIN 0.10 限定哪些相近的切孔能一起计数。
  • 带 LENGTH … WITHIN … 的几行还会检查与宽线直接相连的细线。宽线满足宽度和长度条件时，细线上距它足够近的过孔也受约束。

3.8 VIARULE GENERATE：给工具生成过孔阵列的参数

原文件第 6120–6130 行。

固定 VIA 给出已经画好的图形。VIARULE GENERATE 给出生成阵列时需要的切孔尺寸、孔阵列中心距、上下金属包围量和适用线宽。

这条规则的方孔宽度是 0.05 µm，X、Y 方向中心距都是 0.13 µm。所以两个沿 X 或 Y 相邻的孔，边到边间距是 0.13 − 0.05 = 0.08 µm。文件里的 VIAGEN12_RECT 使用长孔，可以作为一眼带过的对照。

3.9 M1 的 RC、天线、金属密度和电流密度

原文件第 234–236、238–239、243–246、264–266 行。

段落 怎么读
RC RPERSQ 是方块电阻，可以用 R = R_s × L / W 粗算线电阻。另两项分别是单位面积和单位边长的电容系数。文件开头建议用 CapTable 或 QRC 获得更准确的 RC。
天线 PWL 的每一对数分别是扩散区面积和对应的累积天线比上限。第二章示例中的 ANTENNADIFFAREA 提供引脚的扩散区面积数据，工具按这类工艺规则判断天线比。
密度 在 125 × 125 µm 的窗口内检查 M1 金属覆盖率是否在 10%～85%，窗口每次移动 62.5 µm。
电流密度 WIDTH 和 TABLEENTRIES 一一对应。0.09 µm 宽的 M1，表值为 0.9628 mA/µm，乘线宽得到直流电流限值约 86.7 µA。

3.10 VIA10AP_1cut：顶部金属怎么接

原文件第 6098–6106 行。

这三行 LAYER 直接说明 M10 通过 RV 接到 AP。中间的 RV 切孔是 3 × 3 µm。它和前面连接 M1、M2 的过孔写法相同，切孔尺寸差别很大，适合用来收尾。

4.2 第一步：创建四个 RC corner

rc_corner 定义互连的提取条件。工具结合互连几何信息、提取工艺模型、温度和缩放系数，得到寄生 R、C，再用于计算 net delay。

本脚本通过 -qx_tech_file 指定 QRC 的 qrcTechFile。阅读时应把它与 -cap_table 指定的 CapTable 文件区分开；这份脚本没有使用 -cap_table。QRC 文件与 RC corner 的关联方式可参考 Cadence 关于 QRC 工艺文件的说明。

4.3 第二步：创建四组 library set

library_set 定义用哪一组 .lib 时序库。这些库提供 cell delay、输出 slew，以及触发器 setup/hold 等时序模型。PVT 分别表示 Process、Voltage、Temperature，也就是工艺、电压和温度。

Library set 名称 库文件中的工艺标识 电压 温度 在本脚本中的用途
ssg_m40c ssg，慢角 0.81 V -40℃ setup
ssg_125c ssg，慢角 0.81 V 125℃ setup
ffg_m40c ffg，快角 0.99 V -40℃ hold
ffg_125c ffg，快角 0.99 V 125℃ hold

每组包含六个 .lib 文件：三份标准单元库（普通版本、LVT、HVT），以及三份 SRAM 库。同一组内的库文件按相应的工艺、电压和温度配套读取。 LEF 提供单元的物理抽象，.lib 提供时序模型，设计中用到的标准单元和 SRAM 都需要对应的模型。

4.6 第五步：创建四个 analysis view

analysis_view 把 delay corner 和 constraint mode 组合起来。到这里，一个视图中就关联了 .lib 单元时序模型、互连 RC 提取条件和 SDC 约束。

4.7 第六步：分别启用 setup 和 hold 分析视图

创建 view 后，还需要用 set_analysis_view 指定哪些 view 用于 setup、哪些用于 hold：

  • Setup 启用两个视图：ssg、0.81 V，分别搭配 -40℃ 和 125℃ 的 cworst_T 提取条件。
  • Hold 启用两个视图：ffg、0.99 V，分别搭配 -40℃ 和 125℃ 的 cbest 提取条件。

讲解时可以先说，setup 关注数据到达是否太晚，hold 关注数据是否过早变化；本脚本据此选择慢角组合检查 setup、快角组合检查 hold，并且两边都覆盖高低温。

不能直接认定“高温一定最慢、低温一定最快”。 工艺、供电电压和温度共同影响单元延迟，温度反转会让简单的冷热判断失效；这也是讲解当前脚本时需要保留两个温度角的原因。相关现象可参考 Cadence 对库模型与温度反转的说明。具体哪一个视图最差，要看实际库模型和时序报告；这四个视图通过，也不能直接推断未分析的其他组合全部通过。
