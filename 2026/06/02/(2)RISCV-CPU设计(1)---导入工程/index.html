TLEF 是布局布线工具读取的工艺规则文件。 SITE 给出标准单元摆放的基本格子，LAYER 定义金属层和切孔层的轨道、线宽、间距等规则，VIA 提供跨层连接的固定几何，VIARULE GENERATE 提供生成过孔阵列的参数。标准单元 LEF 和 SRAM LEF 则描述具体单元的大小、引脚位置和布线障碍，并引用 TLEF 中定义的层、site 或过孔。

物理库文件 LEF 主要描述单元的尺寸、引脚位置和布线阻挡，以及工艺的金属层和基本布线规则，让后端工具知道单元怎么摆、连线从哪里接入、哪些区域需要避让，是布局布线的基础输入文件。

我们来看一下下面这个lef文件当中

下面这个图就是理解这个lef文件对其中的描述：

RECT 是 Rectangle 的缩写，就是“矩形”。 在 LEF 中，它用两个对角点描述一个矩形区域。

CO（Contact）是接触孔层，通常用于穿过绝缘层，将下方的有源区或多晶硅与第一层金属 M1 接通。LEF 中 CO 层的 OBS 表示该层需要避让的阻挡区域。

数字后端笔记｜从原代码读懂 TLEF

这份笔记从一份 6,326 行的 Technology LEF 中挑出 10 组代码。每组先看原文，再解释它在布局布线里管什么。行号对应原始附件。代码中的 # … 表示节选时省略的行，代码片段按各自原来的位置阅读。

TLEF 给后端工具提供放置和布线共用的工艺定义。 单元 LEF 描述具体单元的外形、引脚和障碍物，并引用 TLEF 中定义的 site、层或过孔。

1. 文件头｜坐标单位、制造网格和扩展规则

原文件第 42–75 行。

  • BUSBITCHARS "[]" 用来表示总线位，例如 A[2]。DIVIDERCHAR "/" 给出层次分隔符。
  • DATABASE MICRONS 2000 表示 1 µm = 2,000 DBU，所以 1 DBU = 0.5 nm。MANUFACTURINGGRID 0.005 给出 5 nm 的几何对齐网格，相当于 10 DBU。
  • USEMINSPACING OBS OFF 让工具按 OBS 的实际形状计算间距。宽障碍物可以触发宽线间距规则。
  • PROPERTYDEFINITIONS 声明扩展属性。后面的 PROPERTY LEF58_SPACING "..." 会把具体间距规则写在引号里。这里的 MAXVIASTACK 4 NOSINGLE RANGE M1 M6 表示在 M1 到 M6 的范围内，叠超过四级时，该堆叠中的过孔都必须是多切孔过孔。

2. SITE core｜标准单元摆放格子

原文件第 77–81 行。

core 是核心区的摆放格子，宽 0.14 µm、高 0.90 µm。标准单元 LEF 里的 SITE core ; 引用这里的定义。你之前画的 AN2D2BWP40P140 是 0.700 × 0.900 µm，刚好是 一行高、五个 site 宽。SYMMETRY Y 表示该 site 支持关于 Y 轴镜像。

3. 四种非布线层｜PO、CO、VTUL_N 和 OVERLAP

原文件第 107–127、1594–1596 行。

类型 怎么读
PO / MASTERSLICE 底层器件工艺相关的层，这里是多晶硅层的抽象。
CO / CUT 接触孔层。ENCLOSURE ABOVE 描述上方图形怎样盖住孔。
VTUL_N / IMPLANT 与器件阈值相关的注入层。用这一段代表文件里重复出现的 VT* 层。
OVERLAP / OVERLAP 可以配合宏单元的 OBS 描述实际摆放占用范围，例如直角多边形的宏占地。

这里可以接回标准单元 LEF 的 OBS → LAYER CO → RECT。单元 LEF 给出障碍图形的坐标，TLEF 定义 CO 这种层。

4. LAYER M1｜走线方向、轨道和线宽

原文件第 171–178 行。END M1 在第 268 行。

  • DIRECTION VERTICAL 表示 M1 优先竖走。竖线沿 Y 方向延伸，相邻两条竖向轨道在 X 方向隔 0.14 µm。
  • OFFSET 0.07 0.000 给出 X、Y 方向的起始偏移。按这组参数生成的竖向轨道可以落在 x = 0.07、0.21、0.35… µm。
  • WIDTH 0.05 是默认线宽，MINWIDTH 和 MAXWIDTH 给出线宽范围。

录屏画两根竖线时，把 PITCH 标在两条中心线之间，把 WIDTH 标在单根线的两条边之间，把 SPACING 标在两根线相邻的边之间。

5. M1 几何规则｜面积、短边、平行间距和线端间距

原文件第 180–182、191–198、210–212 行。

  • AREA 看金属面积。 一块宽 0.05 µm 的独立矩形，单看这条基础规则，长度至少是 0.0115 ÷ 0.05 = 0.23 µm。
  • MINENCLOSEDAREA 看封闭孔洞的面积。 一块金属如果围出一个空洞，这里规定孔洞面积至少是 0.2 µm²。
  • MINSTEP 看轮廓短边。 这里连续短于 0.05 µm 的边最多允许一条。
  • SPACINGTABLE 用来查平行线间距。 两根线分别宽 0.20 和 0.05 µm，平行重叠 0.50 µm。用较大的线宽选 WIDTH 0.180 行，用平行长度选 PARALLELRUNLENGTH 0.470 列，交叉位置就是最小边到边间距 0.100 µm。
  • ENDOFLINE 检查线头。 第一条规则针对端边短于 0.070 µm 的线头，检查范围内要求间距 0.060 µm。WITHIN 0.025 描述沿线头两侧扩展的检查范围。第二条增加了平行邻边条件。

6. LAYER VIA1 和 MINIMUMCUT｜切孔分类和数量

原文件第 270–275、337 行是切孔层节选，第 224–229 行是 M1 上的切孔数量规则。

  • LAYER VIA1 定义 M1 和 M2 之间的切孔层。VSINGLECUT 是 0.05 × 0.05 µm 的方孔。VDOUBLECUT 是 0.05 × 0.13 µm 的一个长孔，规则按两个 cut 计。
  • 以第一条 MINIMUMCUT 为例，宽度超过 0.18 µm 的 M1 线或引脚向上接时，按切孔类别要求两个 VSINGLECUT，或一个 VDOUBLECUT。这里的 WITHIN 0.10 限定哪些相近的切孔能一起计数。
  • 带 LENGTH … WITHIN … 的几行还会检查与宽线直接相连的细线。宽线满足宽度和长度条件时，细线上距它足够近的过孔也受约束。

7. 固定 VIA｜三层矩形组成一个过孔模板

原文件第 1628–1636 行。

这些 RECT 是相对过孔放置点的坐标。叠起来看，底部 M1 是竖长条，中间 VIA1 是方孔，顶部 M2 是横长条。RESISTANCE 8 是这个模板给出的过孔电阻，单位为 Ω。

你之前看到的单元 A2 引脚还有一行。

这行引用的是本文件第 1598–1606 行的另一个模板 VIA12_square，并把它放到单元内坐标 (0.29, 0.40)。录屏时可以把单元 LEF 的引用和 TLEF 的模板定义并排打开。

8. VIARULE GENERATE｜给工具生成过孔阵列的参数

原文件第 6120–6130 行。

固定 VIA 给出已经画好的图形。VIARULE GENERATE 给出生成阵列时需要的切孔尺寸、孔阵列中心距、上下金属包围量和适用线宽。

这条规则的方孔宽度是 0.05 µm，X、Y 方向中心距都是 0.13 µm。所以两个沿 X 或 Y 相邻的孔，边到边间距是 0.13 − 0.05 = 0.08 µm。文件里的 VIAGEN12_RECT 使用长孔，可以作为一眼带过的对照。

9. M1 的 RC、天线、金属密度和电流密度

原文件第 234–236、238–239、243–246、264–266 行。

段落 怎么读
RC RPERSQ 是方块电阻，可以用 R = R_s × L / W 粗算线电阻。另两项分别是单位面积和单位边长的电容系数。文件开头建议用 CapTable 或 QRC 获得更准确的 RC。
天线 PWL 的每一对数分别是扩散区面积和对应的累积天线比上限。你之前看到的 ANTENNADIFFAREA 提供引脚的扩散区面积数据，工具按这类工艺规则判断天线比。
密度 在 125 × 125 µm 的窗口内检查 M1 金属覆盖率是否在 10%～85%，窗口每次移动 62.5 µm。
电流密度 WIDTH 和 TABLEENTRIES 一一对应。0.09 µm 宽的 M1，表值为 0.9628 mA/µm，乘线宽得到直流电流限值约 86.7 µA。

10. VIA10AP_1cut｜顶部金属怎么接

原文件第 6098–6106 行。

这三行 LAYER 直接说明 M10 通过 RV 接到 AP。中间的 RV 切孔是 3 × 3 µm。它和前面连接 M1、M2 的过孔写法相同，切孔尺寸差别很大，适合用来收尾。

录屏串讲

我们先看 SITE core，知道标准单元在什么格子上摆。再看 M1，知道这层优先怎么走、线宽多少、两根线靠多近会违规。走到换层的地方，就看 VIA1 的切孔规则，再看是用一个固定的 VIA 模板，还是按 VIARULE GENERATE 生成过孔阵列。单元 LEF 会引用这些定义，所以初始化设计时，工艺 LEF 和单元 LEF 要配套读入。

录屏可以把时间主要留给第 2、4、5、6、7、8 节。第 5 节现场查一次 PRL 间距表，第 7 节叠画 M1、VIA1、M2 三层矩形。其他节适合当速览或视频配套笔记。

Analysis View 组成如下图所示，可以看到这个组成实际上是层层嵌套的结构，Analysis View是由delay corner和constraint mode来组成，而delay corner则是由rc corner和timing condition来组成，timing condition则是由operation condition和library set组成。

  • 在mmmc文件中，第一步创建 RC Corner，rc文件是工具去抽取net上的rc信息的参考文件，工具可以根据net的长度和金属层信息，去rc文件里面通过查表的方式获取net上的rc值，即寄生电容和寄生电阻等信息。然后innovus工具的时序计算引擎就可以基于这些rc参数去计算net上的delay数值，进而实现整体timing path的delay计算。而我们从上图可以看到，我们这里创建了两个RC Corner，一个是rcmax，这个是基于125℃和cworst这个captable模式下计算得到的，主要用于setup的分析。而另一个则是基于-40℃和cbest这个captable模式下计算得到的，主要用于hold的分析。此外，我们还可以通过调节rc sclae数值去调整innovus计算出来的rc数值，也就是图中的1.05这个数值，使得pr工具计算得到的net delay跟pt里面计算得到的net delay尽可能接近，这部分后续会给出一个理论计算方法。

  • 第二步则是创建library set ，本lab选择了ssg0p81v125c和ffg0p99vm40c这两个WC-BC的工艺角分别用来分析setup和hold时序，一般认为WC工艺角下的setup时序是最差的，BC工艺角下的hold时序是最差的。

  • 第三步创建 constraint mode，这里读取了func 模式下的sdc文件 。

  • 第四步创建 delay corner，将cmax跟ssg0p81v125c组合、cmin跟ffg0p99vm40c进行组合。

  • 第五步创建 Analysis View，我们可以将delay corner和前面的 constraint mode结合起来，这样整个设计的时序信息就是完整的。基于这个 Analysis View去计算时序的时候，就有cell delay信息和net delay信息，一条完整的timing path的delay就可以完成计算。

  • 最后我们需要设置setup分析时需要用cmax这个view，而hold分析时需要用cmin这个view。因为一般我们认为在ssg0p81v125c和cmax组合得到的timing delay是最大的，对于setup计算来说是最悲观的，而ffg0p99vm40c和cmin这个组合得到的timing delay是最小的，对于hold计算来说是最悲观的。如果setup和hold都在最悲观的view下timing是可以接受的，那么其他组合下的setup和hold理论上也是可以接受的。基于这种分析模式，我们可以在innovus中用最小的corner来实现timing收敛，并且corner越少，运行速度和内存占用就越少，对于我们练习也是有帮助的。

rc_corner 定义的是互连的提取条件。工具根据工艺提取文件、温度和缩放系数，得到信号线和时钟线的寄生 R、C，用来计算 net delay。

library_set 定义的是用哪一组 .lib 时序库。这些库提供标准单元和 SRAM 等模块的时序模型，用来算 cell delay、输出 slew，以及触发器的 setup/hold 时间。
